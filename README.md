# 🚀 GDG on Campus PCE – Landing Page

A modern, responsive, and interactive landing page built for the **Google Developer Groups (GDG)**.

Designed to reflect Google's design language while providing an engaging experience through smooth animations, interactive UI elements, and responsive layouts.

---

## 🌟 Preview

> **Build. Learn. Connect.**

A premium landing page showcasing the GDG on Campus community at Pillai College of Engineering.

---

## ✨ Features

- 🎨 Modern Google-inspired UI
- 📱 Fully Responsive (Mobile, Tablet & Desktop)
- 🌙 Dark / Light Theme
- ✨ Smooth Animations
- 🎯 Interactive Navigation
- ❓ FAQ Accordion
- 🎉 Animated Hero Section
- 🎇 Animated Background Effects
- ⚡ Smooth Scrolling
- 🔝 Back to Top Button

---

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Anime.js
- AOS (Animate On Scroll)
- Google Fonts

## 🎯 Objective

The goal of this project was to create a visually appealing, responsive, and interactive landing page for **Google Developer Groups (GDG)** while keeping everything contained within a single HTML file.

---

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/ArnavPatil-09/gdg-landing-page.git
```

Open the project

```bash
cd gdg-landing-page
```

Run

Simply open **index.html** in your browser.

No installation or build tools are required.
